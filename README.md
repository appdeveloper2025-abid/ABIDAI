# ABIDGPT 🤖

A beautiful, responsive ChatGPT clone with JARVIS-like theme, built with React and OpenAI API.

![ABIDGPT Screenshot](https://via.placeholder.com/800x400/0f172a/3b82f6?text=ABIDGPT+Chat+Interface)

## ✨ Features

- 🎨 **JARVIS-inspired Theme** - Dark blue/cyan gradient with glass morphism effects
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile
- 💬 **Multiple Chat Sessions** - Create, manage, and switch between different conversations
- 🔄 **Real-time Typing Indicators** - Visual feedback when AI is responding
- 📝 **Markdown Support** - Rich text formatting with code syntax highlighting
- 💾 **Local Storage** - Conversations are saved in your browser
- 🎯 **Copy to Clipboard** - Easy copying of code blocks and messages
- ⚡ **Fast & Lightweight** - Optimized for performance
